# Tracking

## Set up first, before anything else

1. Verify https://www.oneminuteiman.xyz in Google Search Console (DNS or HTML tag).
2. Submit https://www.oneminuteiman.xyz/sitemap.xml
3. Use the URL Inspection tool on /, /s/anxiety and /about and request indexing.
4. Add Bing Webmaster Tools. It can import from Search Console in one click.

## What to watch, and what would count as working

These are expectations, not promises. A domain days old with no links behaves
differently from an established one, and I have no baseline data to compare to.

**30 days.** Indexed page count above zero and climbing. Impressions appearing on
brand queries ("one minute iman") and on long-tail queries containing a specific
duʿā name. If indexed count is still zero at 30 days, something is blocking it and
that is the thing to investigate, not content.

**60 days.** Situation hubs appearing in the top 50 for their target queries.
Impressions on "dua for X" queries even if position is poor. Entry pages picking
up very long-tail queries such as a hadith reference number.

**90 days.** Any hub inside the top 20 on a winnable query is a genuine signal.
Position 5 to 20 with impressions is the trigger to expand that page.

## The refresh rule

Any page sitting in positions 5 to 20 with impressions gets first priority: extend
the direct answer, add two more FAQs from the actual queries Search Console shows,
and add internal links to it from related hubs.

## Queries to track from day one

Brand: one minute iman.
Hub targets: dua for anxiety, dua for sadness, dua for debt, dua for forgiveness,
dua for travel, dua for protection, dua when sick, dua for parents.
Trust targets: is this dua authentic, sahih hasan daif meaning, dua grading.
Named text: ayat al kursi, sayyid al istighfar, dua of yunus.
