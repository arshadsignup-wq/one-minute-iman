# Verification pipeline

Nothing in `data/` is hand-written. It is generated by these scripts, and regenerating
re-checks every claim against the primary sources.

## Run it

```bash
./scripts/fetch-sources.sh      # primary collections (~62MB, gitignored)
python3 scripts/build.py        # verify the 31 curated entries
python3 scripts/harvest.py      # sweep the corpus for every authentic supplication
python3 scripts/build_all.py    # assign situations, emit the du'a dataset
python3 scripts/fetch-quran.py  # the complete Qur'an, 114 surahs / 6,236 ayat
python3 scripts/build-hadith.py # every authenticated narration in the six books
```

`build.py` caches every Qur'anic verse it fetches to `scripts/quran-cache.json`, so a
re-run needs the network only for references it has not seen before. Delete the cache to
force a fresh fetch.

`fetch-quran.py` asserts the ayah count is exactly 6,236 and fails if it is not.
`build-hadith.py` applies the same grading rule used everywhere else, and reports how
many narrations it refused.

Then refresh `data/` (entries.json, situations.json, index.json) from `scripts/`.

## The four checks

| Check | What it means |
|---|---|
| Hadith exists | The cited number resolves in the primary collection |
| Anchor present | A distinctive Arabic fragment really occurs in that hadith |
| Span is a substring | The Arabic *shown on the site* is verbatim from the source, never retyped |
| Grade rule | Outside al-Bukhārī/Muslim, authenticating verdicts must outweigh weakening ones |

Dissent is never discarded: any weakening verdict is stored and printed on the entry page.

The rule has real teeth. It has rejected a wrong hadith number, a duʿā whose popular
chain is graded ḍaʿīf, and **273 narrations** during the corpus sweep.

## Files

- `manifest.py`: the 31 curated entries (hand-written title, translation, context)
- `build.py`: verifies the curated entries, pulls Qur'anic text from the Quran.com API
- `harvest.py`: extracts every quoted supplication across the six books, dedupes across
  collections, keeps the strongest chain and records the parallels
- `lexicon.py`: situations, the phrasings people actually type, and Arabic patterns
- `build_all.py`: merges both tiers and assigns situations

## How a situation is assigned

A situation sticks to a harvested supplication only when the **duʿā's own Arabic wording**
carries the theme (`AR_PATTERNS`), not merely because the surrounding narration mentions
it in passing. Where no Arabic pattern exists, a keyword in a long narration must appear
more than once. This is what stops a duʿā about the grave being filed under "debt".

## Ad-hoc lookup

```bash
python3 scripts/h.py get bukhari 6345      # fetch by reference, with gradings
python3 scripts/h.py search "anxiety"      # search English text
python3 scripts/ar.py "اكفني بحلالك"        # search Arabic, diacritic-insensitive
```
